## 1. Project Overview & Target Objectives
The objective is to emulate a fully functional scientific calculator (functional parity matching the Casio fx-570MS / fx-82MS series) inside an authentic, salvaged Casio fx-82MS plastic enclosure. The device must operate in dual modes:
1. Local Deterministic Mode: Handles standard algebraic evaluation, trigonometry, logs, and base conversions locally via a C++ parsing engine running on the microcontroller.
2. Cloud AI Mode: Leverages an integrated Wi-Fi stack to dispatch complex, multi-modal inquiries or conversational math expressions via an HTTPS POST request to the Gemini API, parsing the returning JSON chunk to display natural language solutions.

## 2. Hardware Architecture & System Constraints
* Compute Module: Standard ESP32-C3 (Single-core RISC-V processor running at 160MHz).
* Display: Standard 16x2 Character LCD driven via an I2C I/O backpack interface.
* Keypad Input: The original Casio integrated 40-button keyboard layout. 
    - Circuit Typography: Interdigitating copper traces bridged by a conductive carbon dot rubber membrane array.
    - Matrix Layout: Wired internally as a 7x8 matrix layout (7 Row lines / 8 Column lines).
* Electrical Isolation Strategy: The original calculator processor chip (epoxy blob) remains intact on the PCB to preserve structural rigidity but has its power plane completely disabled by permanently hard-wiring the 'BRESET' trace directly to the 'VSS' (GND) plane, placing its internal logic gates into a permanent high-impedance shutdown state.
* Power Subsystem: 4.2V Lithium-Polymer (LiPo) battery. To prevent brownouts during transient Wi-Fi current spikes, the raw battery voltage is conditioned via an external Buck-Boost regulator module to deliver a constant, unwavering 3.3V rail directly to the ESP32-C3's 3.3V power bus.
